# Module: structures/sites.py

## Overview

The `sites.py` module provides three dataclass types for representing atomic sites in different storage modes: `WyckoffSite` for symmetric crystal storage, `PointGroupSite` for symmetric molecular storage, and `AtomSite` for explicit atomic representation. These site types are the fundamental building blocks of USIF structures, enabling efficient storage through symmetry-aware representation.

**Purpose**: Provide type-safe, immutable site representations for different storage modes with proper equality comparison using coordinate tolerance.

**Role in Architecture**: Foundation layer for structure representation - used by USIFStructure to store atomic positions in different modes.

## Architecture

The module consists of three dataclasses, all using Python's `@dataclass` decorator:

1. **WyckoffSite**: For CRYSTAL + SYMMETRIC mode
2. **PointGroupSite**: For MOLECULE + SYMMETRIC mode  
3. **AtomSite**: For FULL_ATOMIC mode (both crystals and molecules)

All site classes implement custom `__eq__` methods using coordinate tolerance for floating-point comparison.

## Key Components

### WyckoffSite Class

Represents a Wyckoff position for symmetric storage of periodic (crystal) structures.

**Attributes**:
- `atomic_number: int`: Atomic number (Z) of the element
- `multiplicity: int`: Number of equivalent positions generated by symmetry
- `coords: Tuple[float, float, float]`: Fractional coordinates (0-1 range)
- `occupancy: float = 1.0`: Site occupancy (default: 1.0 for fully occupied)

**Characteristics**:
- Used only for periodic structures (crystals)
- Coordinates are fractional (relative to unit cell)
- Multiplicity represents symmetry-equivalent positions
- Occupancy allows partial occupation (e.g., 0.5 for 50% occupied)

**Equality Comparison**: Uses `SymmetryConstants.COORDINATE_TOLERANCE` (1e-6 Å) for coordinate and occupancy comparison.

**Usage Example**:
```python
from usif.structures.sites import WyckoffSite

# Create Wyckoff site for Si in diamond structure
wyckoff = WyckoffSite(
    atomic_number=14,  # Silicon
    multiplicity=8,    # 8 equivalent positions
    coords=(0.0, 0.0, 0.0),  # Fractional coordinates
    occupancy=1.0      # Fully occupied
)

# Create partially occupied site
partial_site = WyckoffSite(
    atomic_number=11,  # Sodium
    multiplicity=4,
    coords=(0.5, 0.5, 0.5),
    occupancy=0.75     # 75% occupied
)
```

### PointGroupSite Class

Represents a point group symmetric position for symmetric storage of non-periodic (molecular) structures.

**Attributes**:
- `atomic_number: int`: Atomic number (Z) of the element
- `multiplicity: int`: Number of equivalent positions generated by point group symmetry
- `coords: Tuple[float, float, float]`: Cartesian coordinates in Angstroms
- `occupancy: float = 1.0`: Site occupancy (default: 1.0)

**Characteristics**:
- Used only for non-periodic structures (molecules)
- Coordinates are Cartesian (absolute positions in Å)
- Multiplicity represents point group symmetry-equivalent positions
- No lattice reference (molecular structures)

**Equality Comparison**: Uses `SymmetryConstants.COORDINATE_TOLERANCE` (1e-6 Å) for coordinate and occupancy comparison.

**Usage Example**:
```python
from usif.structures.sites import PointGroupSite

# Create point group site for H2O (C2v symmetry)
oxygen = PointGroupSite(
    atomic_number=8,   # Oxygen
    multiplicity=1,    # Unique position
    coords=(0.0, 0.0, 0.0),  # Cartesian coordinates (Å)
    occupancy=1.0
)

hydrogen = PointGroupSite(
    atomic_number=1,   # Hydrogen
    multiplicity=2,    # 2 equivalent H atoms
    coords=(0.757, 0.586, 0.0),  # Cartesian coordinates (Å)
    occupancy=1.0
)
```

### AtomSite Class

Represents an explicit atomic site with optional per-atom properties. Used for FULL_ATOMIC storage mode.

**Attributes**:
- `atomic_number: int`: Atomic number (Z) of the element
- `coords: Tuple[float, float, float]`: Coordinates (fractional for crystals, Cartesian for molecules)
- `properties: AtomicProperties = field(default_factory=AtomicProperties)`: Per-atom properties (forces, charges, etc.)

**Characteristics**:
- Used for both crystals and molecules in FULL_ATOMIC mode
- Coordinates are fractional for crystals, Cartesian for molecules
- Supports per-atom properties (forces, charges, magnetic moments, velocities)
- No multiplicity (each site represents one atom)

**Equality Comparison**: Uses `SymmetryConstants.COORDINATE_TOLERANCE` for coordinate comparison and delegates property comparison to `AtomicProperties.__eq__`.

**Usage Example**:
```python
from usif.structures.sites import AtomSite
from usif import AtomicProperties

# Create atom site without properties
atom = AtomSite(
    atomic_number=14,  # Silicon
    coords=(0.0, 0.0, 0.0)  # Fractional for crystal
)

# Create atom site with properties
atom_with_props = AtomSite(
    atomic_number=14,
    coords=(0.0, 0.0, 0.0),
    properties=AtomicProperties(
        force=(0.1, 0.2, 0.3),  # Force vector (eV/Å)
        charge=0.5,              # Atomic charge (e)
        magmom=2.0               # Magnetic moment (μB)
    )
)
```

All three classes are dataclasses with:
- **Primitive types**: int, float, Tuple[float, float, float]
- **Optional AtomicProperties**: For AtomSite only
- **Default values**: occupancy=1.0 for symmetric sites, AtomicProperties() for AtomSite

## Usage Patterns

### Creating Sites for Crystal Structure

```python
from usif.structures.sites import WyckoffSite
import numpy as np

# NaCl structure: Na at (0,0,0), Cl at (0.5,0.5,0.5)
na_site = WyckoffSite(
    atomic_number=11,
    multiplicity=4,  # 4 equivalent Na positions
    coords=(0.0, 0.0, 0.0),
    occupancy=1.0
)

cl_site = WyckoffSite(
    atomic_number=17,
    multiplicity=4,  # 4 equivalent Cl positions
    coords=(0.5, 0.5, 0.5),
    occupancy=1.0
)

wyckoff_sites = [na_site, cl_site]
```

### Creating Sites for Molecular Structure

```python
from usif.structures.sites import PointGroupSite

# Water molecule (C2v symmetry)
oxygen = PointGroupSite(
    atomic_number=8,
    multiplicity=1,
    coords=(0.0, 0.0, 0.0),  # Cartesian (Å)
    occupancy=1.0
)

hydrogen = PointGroupSite(
    atomic_number=1,
    multiplicity=2,  # 2 equivalent H atoms
    coords=(0.757, 0.586, 0.0),  # Cartesian (Å)
    occupancy=1.0
)

point_group_sites = [oxygen, hydrogen]
```

### Creating Atom Sites with Properties

```python
from usif.structures.sites import AtomSite
from usif import AtomicProperties

# Create atom sites for full atomic representation
atoms = []
for i, (atomic_num, coords) in enumerate(atomic_data):
    # Create properties for each atom
    props = AtomicProperties(
        force=forces[i] if forces is not None else None,
        charge=charges[i] if charges is not None else None
    )
    
    atom = AtomSite(
        atomic_number=atomic_num,
        coords=coords,
        properties=props
    )
    atoms.append(atom)
```

## Implementation Details

### Coordinate Systems

- **WyckoffSite**: Fractional coordinates (0-1 range) relative to unit cell
- **PointGroupSite**: Cartesian coordinates in Angstroms (absolute positions)
- **AtomSite**: Fractional for crystals, Cartesian for molecules (depends on structure type)

### Equality Comparison

All site classes use tolerance-based comparison:
- Coordinates compared with `SymmetryConstants.COORDINATE_TOLERANCE` (1e-6 Å)
- Occupancy compared with same tolerance
- AtomicProperties equality uses its own tolerance-based comparison

This ensures robust comparison of floating-point values while maintaining precision.

### Dataclass Design

Using `@dataclass` provides:
- Automatic `__init__`, `__repr__`, `__eq__` generation
- Type hints for better IDE support
- Immutability potential (can add `frozen=True` if needed)
- Easy serialization support

### Default Values

- `occupancy=1.0`: Most sites are fully occupied
- `properties=field(default_factory=AtomicProperties)`: Creates new instance per AtomSite to avoid shared state
